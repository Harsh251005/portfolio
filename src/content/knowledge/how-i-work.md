Four habits that took me longer to learn than they should have:

:::more[And four things I won't build]
- **Something that hides what it is.** If a machine is talking to you, you
  should know in the first sentence.
- **A demo pretending to be a product.** If it only works in the walkthrough,
  it doesn't work.
- **A confident answer to a question it can't answer.** "I don't know" is more
  useful than a guess that sounds sure.
- **Automation where someone else pays for the mistakes.** If a failure means a
  missed appointment or a wrong demand for money, a person has to be in the loop.
:::
